# 📚 BookNest

**BookNest** is a React-based web app that helps users discover books using the Google Books API. Whether you're searching by author or title, BookNest makes it easy to find your next favorite read.

---

## 🚀 Features

- 🔍 Search books by name or author
- 📖 View detailed book descriptions
- 🖼️ Book cover previews
- 📦 API integration with Google Books
- 💾 Local storage support for session persistence
- 📱 Fully responsive for mobile and tablets

---

## 🛠️ Tech Stack

- **React** (Frontend)
- **Axios** (API requests)
- **CSS3** (Responsive styling)
- **Google Books API**
